This program should track the character's skills through character creation and after it. Keep in mind that there are rules on how many skills a character can have and how skilled they can be during stages of character creation.

Skills should be tracked by the system rather than the user.

I think we should end up displaying a 2 section approach.

Section one containing proficient skills

Section two containing the remaining skills.

We should be able to collapse these sections.

A useful feature would be to allow rolling a Skill Check by clicking on a Skill. And in tracking the skill, the system will know how to modify it based on skill level and any applicable talents.

For the non proficient skills, while it is collapsed we could have a generic roll unskilled option. I need to verify if stats or other modifiers need to be taken into account for that.
